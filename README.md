## Estado final del proyecto

El sistema CRUD de productos permite crear, buscar, actualizar y eliminar productos. Los datos se guardan en un archivo Excel y el proyecto se desarrolló con Python y la librería openpyxl.

Para el trabajo en equipo usamos GitHub para el control de versiones y Trello para organizar las tareas bajo metodología ágil.
